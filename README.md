# Unit Converter

Simple unit converter made in Python.

It can convert:
- Length (m, km, cm, mm, inch, ft, mile)
- Weight (kg, g, lb, oz)
- Temperature (C, F, K)

## How to run

```
python converter.py
```

Then choose an option from the menu and enter the value and units.

## Example

```
1. Length
2. Weight
3. Temperature
4. Exit
Choose option: 1
units: m, km, cm, mm, inch, ft, mile
Enter value: 5
From unit: km
To unit: mile
5.0 km = 3.106863683249034 mile
```
